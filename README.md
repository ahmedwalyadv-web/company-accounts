# نظام الحسابات الداخلي للشركة

نظام ويب داخلي لإدارة حسابات الشركة، بيشتغل بلينك واحد تقدر تدخل عليه وتعدّل من أي مكان (موبايل، لابتوب، أي جهاز فيه إنترنت).

## المميزات

- تسجيل دخول بصلاحيات لكل مستخدم (يوزر واحد لكل موظف)
- أدوار جاهزة وقابلة للتعديل: مدير النظام، محاسب، مبيعات، مسؤول مصروفات — وتقدر تعمل أدوار جديدة وتحدد كل دور يشوف ويعدل في إيه بالظبط
- اسم الشركة واللوجو قابلين للتعديل من الإعدادات
- شجرة حسابات هرمية (أصول، خصوم، حقوق ملكية، إيرادات، مصروفات) وتقدر تضيف حسابات فرعية
- خزنة بترصد كل حركة تلقائيًا (وارد/منصرف) ورصيدها بيتحدث لحظيًا مع كل عملية
- 4 موديولات أساسية: مشتريات، مصروفات، مبيعات، استلام فلوس — كل عملية فيها: التاريخ، الطرف (مورد/مستلم/عميل)، السبب، المبلغ، ووصف
- أسباب الصرف قابلة للتعديل من الإعدادات (مرتبات، مصروفات تشغيل، إيجار... وتقدر تضيف أي سبب جديد)
- كل البيانات متخزنة في قاعدة بيانات حقيقية (PostgreSQL) — مش ملفات محلية، فالبيانات محفوظة ومتاحة من أي جهاز

## يوزر الأدمن الافتراضي

بعد أول تشغيل هيتعمل يوزر أدمن تلقائي:

- **اسم المستخدم:** admin
- **كلمة المرور:** admin123 (أو القيمة اللي حطيتها في `ADMIN_PASSWORD`)

**غيّر كلمة المرور دي فورًا من "تغيير كلمة المرور" بعد أول تسجيل دخول.**

## التشغيل محليًا (للتجربة على جهازك)

```bash
npm install
cp .env.example .env
# عدّل DATABASE_URL في .env لقاعدة بيانات Postgres عندك
npm run db:init   # يعمل الجداول ويزرع البيانات الافتراضية (مرة واحدة فقط)
npm start
```

هيفتح على `http://localhost:3000`
